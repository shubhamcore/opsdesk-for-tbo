## Run it
```bash
pip install -r requirements.txt
cd frontend && npm ci && npm run build && cd ..   # optional: backend/static already holds the build
python -m database.seed_data.seed                 # synthetic dataset (49 tickets)
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```
Open http://localhost:8000 — sign in with a seeded identity (demo password `OpsDesk#2026`) or
the one-click demo cards.

## Not included
`node_modules` (reproducible with `npm ci`), runtime export CSVs (generated by the exporter),
WAL sidecar files (the database in the archive is checkpointed).

## Honest limits
Synthetic data only; no external LLM, Jira, supplier API or email delivery; single-node SQLite;
Postgres/DuckDB tiers are architecture, not deployment. See README §Limitations.
